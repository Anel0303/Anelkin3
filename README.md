def generate_lesson(subject, topic, grade, language, duration):
    """
    Генерирует структуру урока на основе введённых данных.
    """

    lesson = f"""
ПЛАН УРОКА

Предмет: {subject}
Класс/группа: {grade}
Тема: {topic}
Язык: {language}
Продолжительность: {duration} минут

1. Цель урока
- Познакомить учащихся с темой «{topic}».
- Сформировать практические навыки по данной теме.
- Развить логическое и алгоритмическое мышление.

2. Ожидаемые результаты
После урока учащиеся смогут:
- объяснить основные понятия темы;
- применять полученные знания на практике;
- выполнять практические задания;
- оценивать результаты своей работы.

3. Ход урока

Организационный этап — 3 минуты
- Приветствие.
- Проверка присутствующих.
- Подготовка к уроку.

Актуализация знаний — 7 минут
- Повторение предыдущей темы.
- Краткий опрос учащихся.

Изучение нового материала — 15 минут
- Объяснение темы: «{topic}».
- Демонстрация примеров.
- Ответы на вопросы учащихся.

Практическая работа — 20 минут
Задание 1:
Выполнить практическое задание по теме.

Задание 2:
Решить задачу самостоятельно.

Задание 3:
Проверить результат и исправить ошибки.

Закрепление — 5 минут
- Краткий тест.
- Вопросы по теме.
- Обсуждение результатов.

Рефлексия — 3 минуты
Метод «Светофор»:
🟢 Всё понятно.
🟡 Остались вопросы.
🔴 Тема требует дополнительного объяснения.

4. Домашнее задание
Повторить тему «{topic}» и выполнить практическое задание.

5. Оценивание
Оценивание проводится по результатам практической работы,
активности на уроке и выполнения заданий.
"""

    return lesson
